# Security Policy

## Scope

This technical preview is local-only and does not execute task actions, make
network requests, or accept credentials.

## Reporting a Vulnerability

Do not include credentials or private Aegis Stable material in public issues.
Use GitHub's private vulnerability reporting for this repository after the
owner enables it in the repository security settings. Until that setting is
enabled, contact the repository owner privately through GitHub.

## Supported Version

Only the latest code on the default branch is supported during the technical
preview.
